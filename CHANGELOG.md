# V5.0.0

- support Filament v5 and Laravel 12 / 13 (the Filament v4 line continues on the `v4` branch)
- requires `tomatophp/filament-alerts` ^5.0 and allows `laravel-notification-channels/fcm` ^5.0 or ^6.0, so installing no longer fails on a locked `lcobucci/jwt` 4.x (#9)
- public notifications (no selected user) are now sent to every user that has an FCM token (#11, thanks @islamV)
- single user mobile notifications are queued on `filament-alerts.queue` again, and are skipped when the user no longer exists
- README: the service worker is generated by `php artisan filament-fcm-driver:install`
